# 🎮 摸鱼小游戏

基于 Node.js + Socket.IO 的局域网实时联机小游戏平台，支持五子棋、中国象棋、黑白棋等多种棋类，适合工作间隙与同事来一局轻松对战。

## 技术栈

| 层级 | 技术 |
|------|------|
| 服务端 | Node.js + Express 5 + Socket.IO 4 |
| 前端 | 原生 HTML/CSS/JS（无框架） |
| 棋盘渲染 | Canvas 2D API |
| 实时通信 | WebSocket（Socket.IO） |
| 共享模块 | `shared/chess-logic.js` 同时运行于浏览器和 Node.js |

## 快速开始

```bash
# 安装依赖
npm install

# 启动服务器
npm start

# 访问
# 本机: http://localhost:3000
# 局域网: http://<你的IP>:3000
```

## 功能总览

### 1. 大厅与房间系统

- **房间大厅**：实时展示所有已创建的房间，包括游戏类型、参与者、观战人数、房间状态和简介
- **创建房间**：选择游戏类型（五子棋/象棋），弹窗填写房间简介（可选，限100字），填写后创建房间
- **加入房间**：通过房间卡片一键加入，或输入房间ID加入；支持选择角色（参与者/观战者）
- **空房间自动销毁**：无人房间在 10 分钟后自动销毁，每分钟检查一次

### 2. 五子棋

- 15×15 标准棋盘，Canvas 绘制带渐变效果的棋子
- 黑棋先行，五子连珠获胜
- 棋盘满则平局
- 鼠标悬停预览落子位置

### 3. 中国象棋

- 9×10 标准棋盘，楚河汉界、九宫格斜线、星位标记完整呈现
- 棋子用中文汉字渲染（帅仕相马车炮兵 / 将士象馬車砲卒）
- **完整规则引擎**（`shared/chess-logic.js`）：
  - 7 种棋子走法验证：帅/将、仕/士、相/象、马、车、炮、兵/卒
  - 蹩脚规则：马蹩腿、象蹩脚
  - 九宫限制：帅/将/仕/士不能出九宫
  - 过河限制：相/象不能过河，兵/卒过河后可横走
  - 炮翻山：移动时不能跳子，吃子时恰好隔一子
  - 飞将规则：帅将不能面对面
- **将军检测**：实时判断是否被将军，显示将军提示
- **将杀/困毙判定**：无合法走法时自动判负
- **送将禁止**：不允许走出导致己方被将军的棋步
- **交互方式**：点击选子 → 显示合法走法（绿点可移动，红圈可吃子）→ 点击目标位置走子
- **走子高亮**：上一步移动的起始和目标位置高亮显示

### 4. 角色系统

- **参与者**：可以开始游戏、走棋、编辑房间简介、重新开始
- **观战者**：旁观对局，不能操作，可发送聊天消息
- 加入房间时可自由选择角色（参与者满 2 人后只能选观战）

### 5. 自对弈模式

- 单人即可开始游戏，系统创建虚拟玩家
- 同一用户同时控制红黑双方，轮流走棋
- 服务端通过动态切换 `myColor` 实现回合感知
- 自对弈模式下回合提示显示当前执棋方

### 6. 房间聊天

- 房间内实时聊天，所有参与者和观战者可见
- 系统消息自动推送（创建房间、加入/离开、游戏开始等）
- XSS 防护：聊天内容经过 `escapeHtml` 转义
- 消息限制 200 字

### 7. 房间简介

- **创建时设置**：创建房间弹窗中输入简介（可选，按 Enter 快速确认，或点击跳过）
- **大厅展示**：房间卡片以斜体引号样式展示简介
- **房间内展示**：左侧边栏房间信息区域显示简介
- **房间内编辑**：参与者可随时编辑简介，实时同步到大厅
- 简介限制 100 字

### 8. 其他功能

- **昵称系统**：随机生成初始昵称，支持随时改名（限 20 字）
- **再来一局**：对局结束后可重新开始，保留房间和玩家
- **断线处理**：玩家断开连接自动离开房间，对局中离开则对方获胜
- **响应式布局**：适配不同屏幕尺寸

## Socket.IO 事件

| 事件 | 方向 | 说明 |
|------|------|------|
| `welcome` | S→C | 连接成功，返回 socketId |
| `set-name` | C→S | 设置昵称 |
| `get-rooms` | C→S | 请求房间列表 |
| `room-list` | S→C | 推送房间列表 |
| `create-room` | C→S | 创建房间（含游戏类型和简介） |
| `room-created` | S→C | 房间创建成功 |
| `join-room` | C→S | 加入房间（含角色选择） |
| `room-state` | S→C | 推送房间完整状态 |
| `start-game` | C→S | 开始游戏 |
| `toggle-self-play` | C→S | 切换自对弈模式 |
| `make-move` | C→S | 落子/走子 |
| `restart-game` | C→S | 再来一局 |
| `edit-description` | C→S | 编辑房间简介 |
| `chat-message` | 双向 | 聊天消息 |
| `leave-room` | C→S | 离开房间 |
| `error-msg` | S→C | 错误提示 |
